# UEFADrawApp

Dieser Ordner ist der Platzhalter fuer die spaetere SwiftUI-App.

## Rolle

- Visualisierung der Auslosung
- Bedienung der Simulation
- Anzeige von Regeln, Sperren und Ergebnissen

## Erwartete naechste Dateien

- App-Einstiegspunkt
- Hauptansicht
- Setup- und Ergebnisansichten

## Abhaengigkeit

Die App soll die Logik aus `DrawEngine` verwenden und keine Auslosungsregeln selbst enthalten.
