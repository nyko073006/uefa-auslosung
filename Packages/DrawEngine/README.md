# DrawEngine

Dieses Paket enthaelt die fachliche Kernlogik fuer die Auslosung.

## Zweck

- Modellierung von Teams, Toepfen und Regelwerken
- Ablauf der Ziehung ohne UI-Abhaengigkeiten
- Deterministische Simulation per Seed

## Leitsatz

Alles, was die Auslosung fachlich entscheidet, gehoert hierher. Die SwiftUI-App soll nur anzeigen und steuern, aber keine Regeln selbst erfinden.

## Naechste Inhalte

- Domain-Modelle
- Regelpruefung
- Zufalls- und Seed-Handling
- Ergebnis- und Fehlerdarstellung fuer Debug und Tests
