# Projekt-AGENTS

## Sprache
- Kommunikation und Dokumentation in Deutsch, moeglichst in ASCII-Schreibweise.

## Fokus
- Dieses Repo orchestriert die Entwicklung einer SwiftUI-App zur Simulation einer UEFA Champions League Auslosung.
- Alle Aenderungen muessen auf dieses Ziel einzahlen.

## Arbeitsweise
- Erst lesen, dann aendern.
- Kleine, testbare Schritte bevorzugen.
- Simulationslogik deterministisch und mit Seed pruefbar halten.
- UI und Fachlogik strikt trennen.
- Regeln der Auslosung immer dokumentieren, wenn sie veraendert oder vereinfacht werden.

## Technische Leitplanken
- SwiftUI fuer die UI.
- Reine Fachlogik in separaten Modulen oder Dateien halten.
- Keine hart kodierten Ergebnisse.
- Keine Geheimnisse, Tokens oder API-Schluessel ins Repo schreiben.

## Dokumentation
- Neue Entscheidungen in `docs/` festhalten.
- Offene Fragen sichtbar lassen, bis sie geklaert sind.
