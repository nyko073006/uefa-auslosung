# Produktvision

Die App soll eine UEFA Champions League Auslosung als klare, glaubwuerdige Simulation erlebbar machen.

## Ziele

- Teams, Toepfe und Restriktionen sichtbar machen
- Jede Ziehung Schritt fuer Schritt erklaeren
- Zufall kontrollierbar und reproduzierbar machen
- Ein Ergebnis liefern, das sich fuer Demo, Test und Erklaerung eignet

## Zielgruppe

- Fussballfans, die die Auslosung verstehen wollen
- Nutzende, die eine interaktive Demo erwarten
- Spaetere Entwickler, die die Regeln testen und erweitern wollen

## Erfolgskriterien

- Ein kompletter Draw laesst sich ohne manuelle Eingriffe ausfuehren
- Die App zeigt nachvollziehbar, warum ein Matchup erlaubt oder gesperrt ist
- Gleicher Seed erzeugt gleiche Ergebnisse

## Nicht-Ziele zum Start

- Keine Echtzeit-Anbindung
- Kein Multiplayer
- Keine ueberladene Turnierverwaltung vor der Kernsimulation
